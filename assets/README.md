# Icon

The iroh-share mascot: a waving server, in the style of the iroh link
extension icon.

- `icon.svg`: 48 px and larger.
- `icon-32.svg`, `icon-16.svg`: hand-tuned pixel art for small sizes,
  generated by `pixels.py`. Edit the grids there, then run `python3 pixels.py`.

Rendered files, regenerated after changing a source:

- `icon-256.png`: the GUI window icon (`rsvg-convert -w 256 -h 256 icon.svg -o icon-256.png`).
- `packaging/windows/iroh-share.ico`: 16 and 32 px from the pixel art,
  24 px from `icon-32.svg`, 48–256 px from `icon.svg`, combined with
  ImageMagick (`magick a.png b.png ... iroh-share.ico`).
- `packaging/macos/AppIcon.icns`: an iconset rendered the same way (16 and
  32 px from the pixel art, larger sizes from `icon.svg`), converted with
  `iconutil -c icns`.
